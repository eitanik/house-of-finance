# רעיונות המשך — ארכיון

**ממומש כרגע באפליקציה:** צפייה בתיק שחקן אחר (דירוג → לחיצה על שחקן).

| רכיב | קובץ |
|------|------|
| מסך תיק | `app/player/[uid].tsx` |
| תצוגה | `src/components/PublicPortfolioView.tsx` |
| טעינת שחקן | `src/services/playerView.ts` |

שאר הרעיונות (חוקים שבועיים, קבוצות, חדשות בקנייה) הוסרו מהקוד — נשארו כהצעות לעתיד בלבד.
