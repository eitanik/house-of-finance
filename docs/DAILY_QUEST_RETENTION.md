# יעד יומי + רצף (Daily Quest) — למה ובאיזה מדדים

## למה בחרנו דווקא את זה?

התחרות במשחק נמדדת **לפי שבוע** (שלישי–שישי), אבל שחקנים חיים ב**ימים** (לוח שנה אמיתי). בלי hook יומי, אין סיבה לפתוח את האפליקציה ביום שני או בסוף שבוע — רק “לפני סגירת שישי”.

**יעד יומי + רצף (streak)** נותנים:

1. **משימה קצרה וברורה** בכל יום (“שלח פקודה”, “קדם שעון”, “קנה בת״א”) — קשורה ישירות למסחר, לא מטבעות/ספין גנרי.
2. **Loss aversion** — שבירת רצף כואבת; זה מניע חזרה גם ביום “חלש”.
3. **תגמול תחרותי** — השלמת יעד מוסיפה עד **+5.25** נקודות לציון השבועי (`0.75 × streak`, מקסימום 7 ימים), כך שההabit לא “קוסמטי”.

ייעדים נבחרים **דטרמיניסטית** לפי `(תאריך ישראל + uid)` — אותו שחקן, אותו יום → אותו אתגר; שחקנים שונים → גיוון.

## איך זה עובד בקוד

- מצב: `Player.dailyQuest` (Firestore / מצב מקומי).
- מתעדכן ב: כניסה לאפליקציה, שליחת פקודה, קידום שעון העולם.
- מדדים פנימיים: `activity.appOpensToday`, ספירת פקודות, דקות קידום, וכו'.

## איך נדע אם זה **עובד**?

| מדד | מה נמדוד | סימן להצלחה |
|-----|-----------|-------------|
| **Quest completion rate** | % ימים עם `dailyQuest.completed === true` מכל `calendarDate` פעיל | עלייה שבוע-על-שבוע; יעד >40% |
| **Streak distribution** | היסטוגרמה של `streak` (1, 2, 3…7+) | יותר שחקנים ב-streak ≥3 |
| **DAU / WAU** | שחקנים ייחודיים עם `appOpensToday ≥ 1` / שבוע | DAU/WAU עולה |
| **D1 / D7 retention** | חזרה ביום+1 / יום+7 אחרי הרשמה ראשונה | D7 > baseline לפני הפיצ’ר |
| **Correlation** | השחקנים עם streak גבוה vs דירוג שבועי | בונוס מורגש אך לא “שובר משחק” |

ב-Firebase Analytics / BigQuery (או לוג פשוט ל-`players/*/dailyQuest`) אפשר לייצא:

- `quest_id`, `completed`, `streak`, `appOpensToday` לפי `calendarDate`.

## מה **לא** עשינו (כוונה)

- Push notifications — דורש הרשאות native; השלב הבא אם המדדים טובים.
- תשלום / loot boxes — לא מתאים לתחרות לימודית.

## דיון — אלטרנטивות ששקלנו

| פיצ’ר | יתרון | למה לא עכשיו |
|--------|--------|----------------|
| Push “הדירוג שלך ירד” | חזק מאוד | תשתית + spam |
| ליגות עונתיות | engagement ארוך | מורכבות |
| חדשות עולם יומיות | flavor | פחות מניע פעולה |
| **יעד יומי** | פשוט, מדיד, gameplay | ✅ נבנה |

אם תרצו, אפשר להוסיף **“יעד קבוצתי”** (כל השחקנים יחד 100 פקודות ביום) — דורש ספירה גלובלית ב-Firestore.
