# House of Finance — משחק מסחר וירטואלי

אפליקיית **Expo (React Native) + TypeScript + Firebase** לתחרות שבועית על תשואה ויציבות, עם תיק התחלתי של **₪1,000,000** ו־20 ניירות מדומות (ת"א + ארה"ב).

## הרצה מהירה (הדגמה מקומית — בלי Firebase)

```bash
cd house-of-finance
npm install
npm run web
```

פתחו את הכתובת ש־Expo מדפיס (בדרך כלל `http://localhost:8081`).  
במצב זה המשחק נשמר ב־AsyncStorage; **כמה "שחקנים"** = התנתקות (טאב **עולם** → יציאה) והרשמה עם שם אחר **באותו דפדפן**.

לינק חי זמני לאינטרנט:

```bash
npx expo start --web --tunnel
```

## Firebase (ריבוי שחקנים / לינק קבוע)

1. צרו פרויקט Firebase והפעילו **Authentication** (Anonymous + Email) ו־**Firestore**.
2. העתיקו `.env.example` ל־`.env` ומלאו את מפתחות ה־Web SDK.
3. פרסמו כללים ואינדקסים:

```bash
npx -y firebase-tools@latest login
npx -y firebase-tools@latest use <PROJECT_ID>
npx -y firebase-tools@latest deploy --only firestore
```

4. בניית Web + Hosting:

```bash
npx expo export -p web
npx -y firebase-tools@latest deploy --only hosting
```

## העולם המדומה (מה בחרנו ולמה)

- **20 ניירות** — 10 `TASE` ו־10 `US`, שמות וסימולים **בדויים** (לא נתוני שוק אמיתיים).
- **מחירים** — סérie יומית (פתיחה/סגירה) מ־**Geometric Brownian Motion** עם PRNG דטרמיניסטי (**Mulberry32**, seed גלובלי `424242`).  
  כך כל המכשירים מחשבים **אותם מחירים** בלי להעלות קובץ CSV ל־Firestore.
- **USD/ILS** — סérie נפרדת עם תנודתיות נמוכה סביב ~3.65.
- **שעון משחק** — `world.simMs` משותף; קidום זמן מריץ ביצוע פקודות ממתינות.
- **שעות מסחר** (לפי המפרט):
  - ת"א: **ג**–**ה** 10:00–17:30, **שישי** 10:00–13:50 (שעון ישראל). *יום שני וראשון — סגור במסגרת המפרט.*
  - ארה"ב: **ב**–**ו** 9:30–16:00 (America/New_York).

Epoch התחלתי: **2025-11-04 10:00** ישראל (יום שלישי).

## החלטות על חוקים חסרים / סתירות

| נושא | החלטה |
|------|--------|
| תשואה שבועית | משווים שווי תיק (סגירה) בין **יום שלישי 00:00** ל־**שישי 17:30** שעון ישראל לפי snapshots אחרי קידום זמן. |
| MDD שבועי | על רצף snapshots **בתוך** חלון התחרות; 100 = הירידה המקסימלית **הכי קטנה** בין השחקנים. |
| שחקן יחיד | אחוזון = 100 (לפי הגדרה במפרט). |
| מכירה בשקלים | מומר לכמות יחידות לפי מחיר סגירה/פתיחה בביצוע (כמו קנייה). |
| 20% | נבדק **ברגע הקנייה** על שווי תיק מסומן לסגירה באותו רגע sim. |
| מינוף / short | חסום; מכירה רק מיתרה קיימת. |
| ביטול פקודות | לא נתמך. |
| קidום זמן | כל שחקן מאומת יכול לקדם (בפרודקשן כדאי Cloud Function + הרשאות admin). |

## חוקים שאפשר לנצל (דיווח)

1. **FX בביצוע** — פקודות לניירות US בזמן תנודתיות חזקה בדולר יכולות לקבל שער שונה ממי שהזין פקודה בצהריים (מכוון).
2. **קidום 8 שעות** — מאפשר "לדלג" לסגירות במהירות ולבדוק אסטרטגיות; אין cooldown.
3. **אין עמלות** — מסחר תכוף ללא חיכוך.
4. **מכירה לפי שווי שקלי** — בזמן תנודות חדות, כמות היחידות שנמכרת לא תמיד "עגולה" פסיכולוגית (שברי יחידה מותר).
